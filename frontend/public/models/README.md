# 3D Vehicle Models Directory

Place any standard `.glb` or `.gltf` 3D car models here.
For example:
- `m4.glb`
- `amg_gt.glb`
- `huracan.glb`

The platform includes a built-in procedural luxury supercar renderer that runs smoothly with realistic metallic reflections, aerodynamic bodywork, custom rims, tinted glass, and interactive paint shaders. If a GLTF file is provided in this folder matching the car's `model3D` attribute, the loader will automatically stream and render the exact model geometry!
